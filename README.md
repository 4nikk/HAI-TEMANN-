# 🎓 Ucapan Perpisahan SMA — Kenangan 3 Tahun Putih Abu-Abu

Sebuah web interaktif sederhana dan penuh kenangan yang dibuat khusus untuk teman-teman seperjuangan selama 3 tahun di masa SMA. Dilengkapi dengan animasi, surat perpisahan, serta dua mini-game interaktif yang dipersonalisasi berdasarkan nama masing-masing teman.

---

## ✨ Fitur & Alur Halaman

1. **Halaman 1 — Sambutan & Animasi Tahu Tek**
   - Ilustrasi vektor interaktif sepiring Tahu Tek lengkap dengan uap hangat, siraman bumbu kacang petis, lontong, dan kerupuk yang bergoyang.
2. **Halaman 2 — Surat Ucapan (Sequential Fade-In)**
   - Pesan perpisahan dan ucapan terima kasih yang muncul baris demi baris secara perlahan (*fade-in*), lengkap dengan tombol untuk memutar ulang animasi teks.
3. **Halaman 3 — Mini Game 1: Buket Bunga Namamu 💐**
   - Mengubah setiap huruf dari nama pengguna menjadi rangkaian buket bunga (Mawar, Matahari, Tulip, Daisy, Lavender, dll.) lengkap dengan variasi kertas *wrapping*, pita, dan kartu nama.
4. **Halaman 4 — Mini Game 2: Lagu Untuk Namamu 🎧**
   - Mencocokkan energi nama pengguna dengan rekomendasi lagu hits Indonesia maupun mancanegara beserta desain sampul album kustom dan piringan hitam yang berputar.
5. **Halaman 5 — Halaman Penutup**
   - Pesan perpisahan singkat *"bye-bye teman, terima kasih"* dengan animasi kelopak bunga yang berjatuhan.

## 🚀 Cara Menjalankan & Publikasi di GitHub Pages

Kamu tidak perlu menginstal apa pun karena seluruh aplikasi berjalan dalam satu file (`index.html`).

### 1. Upload ke GitHub
1. Buat repository baru di akun GitHub kamu (misalnya: `kenangan-sma`).
2. Unggah file `index.html` dan `README.md` ini ke dalam repository tersebut.

### 2. Aktifkan GitHub Pages (Gratis)
1. Buka tab **Settings** pada repository kamu.
2. Di menu sebelah kiri, pilih **Pages**.
3. Pada bagian **Build and deployment** > **Branch**, pilih `main` (atau `master`) lalu klik **Save**.
4. Tunggu sekitar 1–2 menit, lalu *refresh* halaman tersebut. Link website kamu akan muncul di bagian atas dan siap dibagikan ke grup kelas!
